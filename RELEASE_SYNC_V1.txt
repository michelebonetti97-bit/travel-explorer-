TRAVEL EXPLORER — SYNC V1
Michele / Denise — Mauritius 2026

NOVITÀ
- Due account separati con sessione persistente.
- Un unico viaggio condiviso tramite codice di 10 caratteri.
- Salvataggio locale IndexedDB prima di ogni invio.
- Coda offline con riallineamento automatico al ritorno della rete.
- Aggiornamenti realtime e avviso con nome di chi ha modificato.
- Unione a tre vie per limitare sovrascritture in caso di modifiche contemporanee.
- Sincronizzazione di itinerari, giornate, budget, spese, documenti,
  checklist e diario.
- Allegati privati Supabase Storage fino a 25 MB per file.
- Service worker V2 con nuovi file disponibili offline.

2. Eseguire supabase_storage_setup.sql nel SQL Editor.
3. Verificare che Authentication contenga soltanto Michele e Denise.
4. Disattivare nuove registrazioni pubbliche.

NOTA
La Publishable key nel browser è pubblica per definizione. La protezione dei dati
è affidata ad autenticazione e Row Level Security. Non inserire mai nel repository
sb_secret, service_role o password del database.
